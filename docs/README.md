# Documentation

Start with [agents](agents.md) if you want your coding agent running Substack for you,
which is what this tool was built for. Start with [installation](installation.md) and
[authentication](authentication.md) if you would rather type the commands yourself.

| Page | Read it when |
|---|---|
| [agents.md](agents.md) | You want Claude Code, Cursor, or Codex driving this. |
| [installation.md](installation.md) | Installing, or the `substack` command is not found. |
| [authentication.md](authentication.md) | Setting up, or a call returned 401. |
| [commands.md](commands.md) | You want every flag and what it does. |
| [frontmatter.md](frontmatter.md) | You are writing a post and want the fields. |
| [markdown.md](markdown.md) | Something did not convert the way you expected. |
| [workflows.md](workflows.md) | Git-backed publishing, backups, migrations, CI. |
| [api-notes.md](api-notes.md) | You are building your own Substack client. |
| [troubleshooting.md](troubleshooting.md) | An error message you want fixed now. |
| [faq.md](faq.md) | Is this allowed, will it break, what about paid posts. |
